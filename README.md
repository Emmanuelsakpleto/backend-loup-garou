# Backend - Loup-Garou (scaffold)

Projet backend minimal TypeScript + Express + Socket.IO pour la V1.

Quick start

1. Installer les dépendances

```bash
cd backend-loup-garou
npm install
```

2. Lancement en dev

```bash
npm run dev
```

3. Build & start

```bash
npm run build
npm start
```

Notes
- Le serveur fourni est un exemple minimal (in-memory store). Remplacez-le par une couche DB (Postgres, Firestore) pour production. Ne pas stocker hostToken en clair en prod.
